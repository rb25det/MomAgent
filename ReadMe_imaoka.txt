対話ログは同じフォルダ内に、予定データはC/ユーザー/ユーザー名/mom--elyza/schedules.json に格納
 ex:
   {
        "summary": "アルバイトがある",
        "datetime_iso": "2025-12-01T20:02:53",
        "importance": "2"
    }

summary:予定内容
datetime_iso:日時(元の時間はリアルタイムで取得)
importance:重要度(1>2>3の順で重要)
