## はじめに

### コンセプト

**LLM × お母さん**

相談しやすい存在No.1である家族をLLMで擬似的に再現し、いつでも、どこでも、何でも、相談できる環境を実現します。

**お母さんAIの3つの役割：**
1. **寄り添う存在**：一人暮らしの学生・社会人の心に寄り添うみんなのお母さん
2. **相談役**：将来後悔しないために今を一緒に考えてくれる頼れる存在
3. **見守り役**：時には叱ってくれる、いつでも応援してくれるお母さん

**お母さんAIの強み：**
- **親身さ** × **相談しやすさ** ：本当のお母さんは親だからこそ言えないことがある。でもお母さんAIなら、親身でありながら、あらゆることを相談できる存在
- **24時間対応**：夜中でも朝でも、いつでも相談可能
- **プライバシー保護**：秘密にできることはお母さんAIに相談できる
- **予定管理**：日々の予定をサポートし、やるべきことを一緒に考える

- **CPU**: 4コア以上推奨

- **OS**: Windows / macOS / Linux
- **Docker**: （オプション）推奨
- **Python**: 3.10以上

## 2. インストール・セットアップ

### 2.1 事前準備

#### Ollamaのインストール
1. https://ollama.ai から自分のOSに対応したOllamaをダウンロード
2. インストール実行
3. ターミナルで以下を実行：
   ```bash
   ollama serve
   ```
   サーバーが起動し、ポート11434でリッスン開始

#### Pythonパッケージのインストール
```bash
cd /path/to/MomAgent
pip install -r requirements.txt
```

### 2.2 初回セットアップ

#### ステップ1：アプリケーション起動
```bash
cd /path/to/MomAgent
python app.py
```

ブラウザで `http://localhost:5000` を開く

#### ステップ2：プロフィール設定

**プロフィール画面で以下を入力：**

| 項目 | 説明 | 例 |
|------|------|-----|
| ニックネーム | お母さんからの呼び名 | 太郎 |
| 性別 | 性別 | 男性 |
| 年齢 | 年齢（省略可） | 22 |
| 学年/役職 | 学生か社会人か | 4年生 |
| 生活リズム | 平日の起床・就寝時間 | 起：7:00 / 寝：23:00 |
| 健康情報 | 朝食頻度、運動頻度 | 朝食毎日 / 週3回 |
| 関心事項 | 関心がある話題 | 就活、将来 |
| 今の悩み | 現在の悩み | インターンシップ対策 |

**入力後、「次へ」をクリック**

#### ステップ3：お母さんの性格設定

**お母さん設定画面で以下を調整：**

| パラメータ | 範囲 | 説明 |
|-----------|------|------|
| 厳しさ | -1.0〜+1.0 | -1.0：甘め / +1.0：厳しめ |
| おしゃべり度 | -1.0〜+1.0 | -1.0：寡黙 / +1.0：おしゃべり |
| 方言 | - | 標準語 / 関西弁 / 博多弁 |
| 対話スタイル | - | □ じっくり聞く / □ アドバイス重視 / □ 褒める |

**複数選択可能。好みに合わせてチェック**

#### ステップ4：チャット開始

「チャット開始」をクリックするとお母さんがご挨拶

```
久しぶりね、元気で過ごしてる？何か話したいことある？
```

## 3. 使い方

### 3.1 チャット画面の使い方

#### 画面構成

```
┌─────────────────────────────────────────────┐
│ お母さんAI  │プロフィール│設定│予定管理    │  ← ナビゲーション
├─────────────────────────────────────────────┤
│                                             │
│  お母さん> 久しぶりね、元気？               │
│                                             │
│           あなた> 就活で悩んでるんだよね    │  ← 会話履歴
│                                             │
│  お母さん> 心配ね。どんなことで悩んでる?  │
│                                             │
├─────────────────────────────────────────────┤
│ メッセージを入力してください...  │ 送信    │  ← 入力欄
└─────────────────────────────────────────────┘
```

#### メッセージ送信方法
1. 下部の入力欄に메시지を入力
2. 「送信」ボタンをクリック（またはEnterキー）
3. お母さんからの返信を待つ

### 3.2 予定管理

#### 予定追加
1. ナビゲーションメニューから「予定管理」を選択
2. 「新規追加」ボタンをクリック
3. 以下を入力：
   - **日付**（必須）：YYYY-MM-DD形式
   - **時間**（省略可）：HH:MM形式
   - **内容**（必須）：予定内容（例：NRI対策、面接）
   - **場所**（省略可）：場所名
   - **優先度**：1（高）〜 5（低）
4. 「保存」をクリック

#### 予定確認
チャットで「今月の予定は？」と聞くと、お母さんが登録済み予定を教えてくれます

```
あなた> 今月の予定は？
お母さん> 今月の予定はこれね。
・2026-01-21 12:00 NRIの対策
・2026-01-28 14:00 最終面接
```

#### 予定編集・削除
予定一覧から編集・削除ボタンをクリック

### 3.3 よくある使い方パターン

#### パターン1：日々の悩みや不安を相談
```
あなた> 最近就活で失敗続きで落ち込んでるんだよね
お母さん> そっか、失敗が続くと気持ち落ちるよね。
       でもね、失敗って成長のチャンスなのよ。
       何が原因だと思う？一緒に考えてみようか。
```

#### パターン2：将来のキャリアについて相談
```
あなた> SIer業界がいいのか迷ってるんだ
お母さん> SIer業界ね。素敵な選択肢やね。
       実はね、こういう点が大事よ...
       あなたはどんな企業で働きたい？
```

#### パターン3：時間管理や予定管理の相談
```
あなた> 明日、面接があるんだけど緊張する
お母さん> そっか、面接があるんだ。緊張もするよね。
       でもね、これまでの準備があるはず。
       予定管理画面で対策状況を確認してみようか。
       そういえば、明日の面接の準備は大丈夫？
```

## 4. 主な機能

### 4.1 自然な対話

お母さんAIは以下のような特徴を持ったお母さんになります：

- **共感する**：あなたの気持ちをまず受け止める
- **質問する**：深掘りして、本当の悩みを引き出す
- **提案する**：あなたのために最適なアドバイスをする
- **励ます**：時には厳しく、時には優しく応援する

### 4.2 会話終了時の自動ナッジ

「ありがとう」「わかった」「頑張るね」など、会話を終わらせるような発言をすると、お母さんが次の予定を自動的に提案してくれます。

```
あなた> わかった、頑張ってみる
お母さん> そうね、頑張るのよ。応援してるからね。
       
       そういえば、2026-01-21 12:00 に『NRIの対策』があるはずよね。準備は大丈夫？
```

### 4.3 365日24時間対応

いつでも相談できるのがお母さんAIの強み。深夜でも朝でも、お母さんが待ってます。

## 5. カスタマイズ

### 5.1 お母さんの性格調整

#### 設定変更方法
1. チャット画面のナビゲーションから「設定」を選択
2. 「厳しさ」「おしゃべり度」などのスライダーを調整
3. 「保存」をクリック

#### 推奨設定プロフィール

**タイプA：甘めのお母さん**
- 厳しさ：-0.5
- おしゃべり度：+0.3
- 対話スタイル：褒める✓

**タイプB：バランスの取れたお母さん**
- 厳しさ：0.0
- おしゃべり度：0.0
- 対話スタイル：じっくり聞く✓、アドバイス重視✓

**タイプC：厳しめのお母さん**
- 厳しさ：+0.5
- おしゃべり度：+0.2
- 対話スタイル：アドバイス重視✓

### 5.2 方言の選択

「設定」→「方言」から以下を選択可能：
- **標準語**：どこでも親しみやすい
- **関西弁**：あたたかみのある関西イントネーション
- **博多弁**：やさしい九州弁

## 6. トラブルシューティング

### Q. お母さんが反応しない
**A.** 以下をご確認ください：
1. Ollamaが起動しているか確認
   ```bash
   ps aux | grep ollama
   ```
2. ブラウザを再読み込み（F5）
3. それでも反応がない場合は、アプリケーションを再起動
   ```bash
   python app.py
   ```

### Q. 同じ予定を何度も催促される
**A.** これは仕様です。会話を終わらせるたびに、次の予定を提案します。予定を対策済みにするか、編集・削除してください。

### Q. 何か敬語が混じっている
**A.** まれに発生します。その場合は「敬語をやめてね」と伝えると改善されます。

### Q. 予定が保存されていない
**A.** セッション内のみの保存のため、ブラウザを閉じると予定が消えます。重要な予定は別途スクリーンショット等で保存してください。

### Q. 設定を変更したのに反映されない
**A.** 設定変更後、モデルの再構築に時間がかかります。30秒ほど待ってからチャットを再開してください。

## 7. よくある質問（FAQ）

### Q. 本当のお母さんの代わりになるのか？
**A.** いいえ、代替ではなく補完です。本当のお母さんとの関係は大切にしながら、親に言えない悩みや、24時間の相談が必要な時にお母さんAIを活用してください。

### Q. 個人情報は安全か？
**A.** 本システムはローカル実行のため、データが外部に送信されることはありません。安心してプライベートなことを相談できます。

### Q. 学習されるのか？
**A.** 本システムは学習機能を持たないため、会話内容が蓄積されることはありません。毎回独立した対話として機能します。

### Q. インターネット接続は必要？
**A.** 初期セットアップ時のOllamaダウンロード以外は不要です。セットアップ後はオフラインでも利用可能です。

### Q. 複数デバイスで使える？
**A.** 同じPCからであれば可能です。別PCでの利用を考えている場合は別途相談してください。
